# DAY 01 — ML Study & Performance Tracker

A beginner-friendly Python project that tracks weekly study hours, analyses test performance, and provides a personalized learning recommendation.

## Features

* Collects student profile information
* Records study hours for seven days
* Calculates total, average, highest, and lowest study hours
* Records five Python test marks
* Calculates test statistics
* Counts passed and failed tests
* Assigns an overall grade
* Generates a personalized preparation status and recommendation

## Python Concepts Used

* Variables and data types
* User input and type conversion
* Arithmetic operators
* Comparison and logical operators
* Conditional statements
* Lists
* For loops
* Built-in functions
* F-strings

## Mini Project: ML Internship Skills Tracker

A command-line Python application that helps a student track the technical skills they are currently learning and have completed during their machine learning internship preparation.

## Project Features

- Collects student profile information
- Displays a structured machine learning roadmap
- Adds unique learning skills
- Prevents duplicate skills
- Marks learning skills as completed
- Displays learning and completed skills
- Calculates skill completion percentage
- Generates a personalized progress status
- Provides a learning recommendation
- Runs through an interactive menu

## Python Concepts Used

- Dictionary for the student profile
- Tuple for the fixed machine learning roadmap
- Set for unique learning skills
- List for completed skills
- Functions for reusable operations
- While loop for the interactive menu
- If, elif and else for decision-making
